# PredictX extension: physics-based analysis of spirometry curves

This repository extends PredictX with a research pipeline for recovering and evaluating clinically relevant measurements from raw forced-expiration curves. The central question is whether a compact mechanistic model can estimate forced vital capacity and the FEV1/FVC ratio when a maneuver ends early or is otherwise incomplete.

The repository is a research prototype. It estimates spirometric airflow obstruction, not a clinical diagnosis of chronic obstructive pulmonary disease. A COPD diagnosis requires clinical context and confirmatory post-bronchodilator spirometry.

## Current evidence

The strongest supported result is the raw-curve parser. Its participant-level FEV1 and FVC reconstruction error is approximately 3 to 4 percent across the 2007-2008, 2009-2010, and 2011-2012 NHANES cycles.

The original five-parameter flow model does not adequately reproduce complete real curves. On cycle F, none of 31,851 curves met the prespecified noise-normalized adequacy criterion. Complete-curve classification also performs worse than pooled direct measurement in the broader reconciliation analysis.

The corrected Cycle F truncation experiment used a fixed 12-second prediction horizon and no measurements or timing information after the cut point. At 2 and 3 seconds, mechanistic extrapolation reduced median FVC error and obstruction false negatives relative to direct use of the truncated endpoint and to the registered extrapolation baselines. This is a positive internal recovery result, not a clinical validation result. Sensitivity remained approximately 40 percent at both cut points, the cohort was constructed from high-quality complete maneuvers, and the complete-curve model still failed its independent adequacy test.

See [Project overview](docs/PROJECT_OVERVIEW.md), [Methods](docs/METHODS.md), [Results](docs/RESULTS.md), and [Limitations](docs/LIMITATIONS.md) for a review-oriented account.

## Repository structure

- `predictx/`: parsing, mechanistic modeling, inference experiments, and evaluation modules
- `tests/`: focused regression and protocol-integrity tests
- `results/`: committed historical result artifacts and audit reports
- `figures/`: figures generated by the analyses
- `docs/`: academic overview, methods, evidence status, limitations, and reproduction instructions

## Installation

Python 3.10 or later is required.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e '.[dev]'
```

The optional simulation-based inference environment is installed with:

```bash
python -m pip install -e '.[inference,dev]'
```

## Verification

```bash
python -m pytest
python -m compileall -q predictx tests
```

Raw NHANES files are intentionally excluded from version control. Follow [Reproducibility](docs/REPRODUCIBILITY.md) to restore the public inputs and regenerate analyses.

## Responsible interpretation

This code is not a medical device and must not be used for diagnosis or treatment decisions. Reported labels are spirometric obstruction surrogates derived from NHANES measurements. They are not independent clinical adjudications.
